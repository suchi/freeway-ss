## 1. 目的と完了条件

2026-10-27に、ユーザーから、速度計を現代の車のダッシュボード風にし、作り込みの度合いを設定で選べるようにする依頼を受けた。同日にユーザーと決めたこと:

- 速度計の表示を、なし・数字だけ・ダッシュボード(シンプル)・ダッシュボード(作り込み)の4段階のドロップダウンにする
- 他車の形(v1.11.0)より先に行う

完了条件:

- 設定画面の「速度計を表示する」のチェックボックスが、「速度計」のドロップダウン(4段階)に置き換わり、OKで保存される(日本語と英語)
- 今の設定値(`ShowSpeedometer`)を引き継ぐ(3.1節)
- 数字だけは、今と同じ見た目になる
- ダッシュボード(シンプル)とダッシュボード(作り込み)が、3.2節と3.3節のとおりに描かれる
- プレビュー(設定画面の小さな窓)と、DPIの違う画面で、大きさが崩れない
- 配置・角度・値の計算のテストがある(4章)
- ユーザーが実機で確認する
- ワークスペースのバージョンが`1.10.0`になっている(このPRの最初のコミットで実施済み)

## 2. 前提(v1.9.0の状態)

- 速度計は、`freeway-scr`の`renderer.rs`の`draw_speedometer`が、左下に琥珀色(#ffb000)の数字と「km/h」をDirectWriteで描く。大きさは`speedometer.rs`の`scale`(DPIに合わせ、低い窓では縮める)で決まる
- 表示する速さは`Scene::speed_kmh`(巡航速度のゆらぎを含む)を`speedometer::displayed_speed`で整数に丸めたもの
- 現地時刻は`Scene::minute_of_day`(起動時のPCの時刻に走った時間を足したもの)で得られる
- 設定は`Settings::show_speedometer`(bool)と、レジストリ値`ShowSpeedometer`(`REG_DWORD`。0か1)
- 画面の文字列は`i18n.rs`の表(ADR-0007)

## 3. 設計

### 3.1 設定

- `freeway-core`に`SpeedometerStyle`(`None`・`Digits`・`SimpleDashboard`・`DetailedDashboard`)を加え、`Settings::show_speedometer`を`speedometer`(既定`None`)に置き換える
- レジストリ値は`Speedometer`(`REG_DWORD`。0: なし、1: 数字だけ、2: ダッシュボード(シンプル)、3: ダッシュボード(作り込み))。0〜3以外は既定値
- 引き継ぎ: `Speedometer`がなく、`ShowSpeedometer`が1なら数字だけ、それ以外はなしとして読む。保存するときは`Speedometer`を書き、`ShowSpeedometer`も「なし以外なら1」で書く(前の版に戻したときにも、表示のオン・オフが残るように)
- 設定画面: 「速度計を表示する」のチェックボックスを、ラベルとドロップダウンに置き換える。文字列は`i18n.rs`の表に加える

| キー | English | 日本語 |
| --- | --- | --- |
| ラベル | Speedometer: | 速度計: |
| なし | None | なし |
| 数字だけ | Digits only | 数字だけ |
| ダッシュボード(シンプル) | Dashboard (simple) | ダッシュボード(シンプル) |
| ダッシュボード(作り込み) | Dashboard (detailed) | ダッシュボード(作り込み) |

### 3.2 ダッシュボード(シンプル)

左下に、円弧のゲージ1つと数字を描く。値は寸法の目安で、見た目に合わせて実装で調整してよい。

- ゲージ: 半径90 px(scale 1)の円弧。開き角は240度(左下の7時半の位置から、右下の4時半の位置まで、時計回り)。目盛りの範囲は0〜180 km/h
- 円弧の地(暗い琥珀。不透明度0.25程度)の上に、0から今の速さまでを明るい琥珀(不透明度0.9程度)で重ねる。線の太さは8 px、端は丸める
- 円弧の中央に今の速さの数字(今の数字の書体・色。大きさは今より少し小さく)、その下に「km/h」
- 速さが180 km/hを超えることはない(巡航速度は最大160 km/h、ゆらぎは±20 km/hで、160 km/hを超えない)。超えた場合も円弧は端で止める

### 3.3 ダッシュボード(作り込み)

左下から下の中央寄りにかけて、現代の車の計器盤を模した表示を描く。値は寸法の目安で、見た目に合わせて実装で調整してよい。

- 背景: 計器全体の後ろに、角の丸い暗い板(黒。不透明度0.45程度)を敷き、道路の光の上でも読めるようにする
- 速度計: 3.2節の円弧に、目盛り(20 km/hごとに長い目盛りと数字、10 km/hごとに短い目盛り)と、今の速さを指す針を加える。中央に今の速さの数字
- 回転計: 速度計の右に、少し小さい円弧(0〜8 ×1000 rpm、6以上は赤)。回転数は速さから求める(6速の自動変速で、100 km/hのとき約2,000 rpm。速さに比例させ、ゆらぎで少し揺れる)
- 情報の行: 計器の下に、現地時刻(`HH:MM`。`Scene::minute_of_day`)・走った距離(`TRIP 123.4 km`。起動してからの距離)・シフトの位置(`D`)を並べる
- 色: 琥珀を基調にし、目盛りの数字と情報の行は白に近い色(不透明度0.7程度)。回転計の6以上は赤

### 3.4 描き方と計算の分け方

- 角度・目盛りの位置・回転数・時刻と距離の文字列など、OSに依存しない計算は、`freeway-scr`の`speedometer.rs`(またはOSに依存しない新しいモジュール)に置き、Linuxでもテストできるようにする
- Direct2Dの描画(円弧の`ID2D1PathGeometry`、線、文字)は`renderer.rs`に置く。速さによらない部分(目盛り・板・地の円弧・目盛りの数字)は、scaleごとに作り置きして使い回す
- 今の`draw_speedometer`と同じく、場面の上に通常の合成で描く。描画の失敗は、今と同じく`EndDraw`の後に報告する
- 大きさは`speedometer::scale`に従う。プレビューの小さな窓では全体が縮み、窓からはみ出さない(はみ出す場合は描かない、でもよい)
- 走った距離を得るため、`Scene`に起動してからの距離(`track_s`)を返す関数がなければ加える

## 4. テスト

`freeway-core`:

- 設定: `SpeedometerStyle`の既定値がなし、0〜3の対応、範囲外は既定値
- 文字列の表のテストが、追加したキーでも通る

`freeway-scr`(OSに依存しない部分はLinuxでも実行):

- 円弧の角度: 0 km/hで始点、180 km/hで終点、その間は比例。範囲外は端で止まる
- 目盛り: 20 km/hごとの数字と10 km/hごとの目盛りの数と角度
- 回転数: 100 km/hで約2,000 rpm、速さに比例、0〜8000の範囲に収まる
- 情報の行: 時刻の書式(`00:00`〜`23:59`)、距離の書式(小数1桁のkm)
- 配置: 典型的な画面(768〜2160の高さ、DPI 100〜200%)とプレビューの大きさで、計器が窓に収まる
- レジストリ(Windowsのみ): `Speedometer`の書き込みと読み戻し、`ShowSpeedometer`だけがあるときの引き継ぎ、範囲外の値
- 描画(Windowsのみ): 既存の非表示ウィンドウのテストで、4段階のどれでも描画が失敗しない

見た目は、ユーザーの実機確認で見る。

## 7. 実装で決めた値

寸法はscale 1(論理ピクセル)での値である。実装の定数は`crates/freeway-scr/src/speedometer.rs`(寸法・配置・計算)と`crates/freeway-scr/src/win/dashboard.rs`(色・不透明度)にある。実機での見た目に合わせて調整してよい。

### 設定

- 保存: 3.1節のとおり。`Speedometer`が範囲外(4以上)のときは、`ShowSpeedometer`の値によらず既定値(なし)。引き継ぎは`Speedometer`がない(または`REG_DWORD`でない)ときだけ
- `Settings::from_raw`の引数に、`Speedometer`の値を最後に追加した(`ShowSpeedometer`の値は`legacy_show_speedometer`として残した)
- 設定画面: ドロップダウンは、ラベル(ID 121)とコンボボックス(ID 105)。ドロップダウンの分だけ、下の項目を6ダイアログ単位下げ、ダイアログの高さを274から280にした

### 共通

- 円弧の開き角: 240度。始点は8時の位置(画面上で3時の向きから時計回りに150度)、終点は4時の位置(同390度)。3.2節の「7時半から4時半」は270度の開きの位置で、同じ節の240度と合わないため、240度を採った
- 速度計の目盛り: 0〜180 km/h。回転計の目盛り: 0〜8000 rpm、6000 rpm以上は赤
- 位置: 左と下の余白は28 px(数字だけと同じ)。大きさは`speedometer::scale`に従う
- 描かない場合: 窓に収まらないとき(狭い窓など)は計器全体を描かない。画面上で6 px未満になる文字(プレビューの「km/h」・目盛りの数字・情報の行など)は描かない
- 色: 琥珀(#ffb000)、白に近い色(#f0f0f0)、赤(#ff3b30)、板は黒
- 書体: Bahnschrift(数字だけと同じ)。中央の数字は今の数字と同じ太さ(SemiLight、桁の幅は一定)。時刻・距離の桁の幅も一定
- 針と円弧には、実際の速さ(ゆらぎを含む小数)を使う。中央の数字だけ整数に丸める

### ダッシュボード(シンプル)

- ゲージ: 半径90、線の太さ8(端は丸める)
- 地の円弧: 琥珀、不透明度0.25。今の速さまでの円弧: 琥珀、不透明度0.9
- 中央: 数字の大きさ44、「km/h」の大きさ16(不透明度0.6)。数字の上端から「km/h」の下端までを、ゲージの中心に合わせる
- 数字は不透明度0.9

### ダッシュボード(作り込み)

- 板: 左下の余白から、幅と高さは338×196(scale 1)。角の半径14、黒、不透明度0.45。内側の余白は14
- 速度計: 半径88、線の太さ8。目盛りは円弧の10(回転計は8)だけ内側から始まり、10 km/hごとの短い目盛り(長さ6、太さ1.5、不透明度0.5)と、20 km/hごとの長い目盛り(長さ11、太さ2、不透明度0.85)。目盛りの数字は大きさ10、円弧の31内側が中心、白に近い色で不透明度0.7。中央の数字は大きさ36
- 針: 円弧の24内側から3内側までの太さ4の線。白に近い色、不透明度0.95
- 回転計: 速度計の右、間隔12。半径54、線の太さ6。0〜6000 rpmは琥珀(地の不透明度0.25)、6000〜8000 rpmは赤(不透明度0.55)。1000 rpmごとに目盛り(長さ7、太さ2。6000 rpm以上は赤)と数字(大きさ9)。針は円弧の16内側から2内側まで、太さ3。中央に「x1000 rpm」(大きさ9、白に近い色で不透明度0.5)。2つの円弧の下端はそろえる
- 回転数: 速さ×20 rpm(100 km/hで2,000 rpm)。速さのゆらぎがそのまま回転数のゆらぎになる。速さに比例するので、巡航速度の最大(160 km/h)でも3,200 rpm(赤い部分には届かない)
- 情報の行: ゲージの下、間隔8、高さ20。時刻(`HH:MM`)は左端、走った距離(`TRIP 123.4 km`)は中央、シフトの位置(`D`、琥珀)は右端。文字の大きさ13、白に近い色で不透明度0.7。時刻は`Scene::minute_of_day`、距離は`Scene::track_s`(メートル)から作る

### 設計と変えたこと

- 3.2節の「7時半から4時半」を、上のとおり8時から4時にした(240度に合わせた)
- 3.4節の「速さによらない部分」の作り置きは、Direct2Dの図形(円弧・目盛り・目盛りの数字)をスタイルとscaleごとに保持する形で実装した。位置は、ゲージの中心への平行移動で与えるため、窓の大きさが変わっても作り直さない
