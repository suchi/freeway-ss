# Phase 7.2 詳細設計: 設定画面の多言語化

- ステータス: 完了(実機確認済み。[#17](https://github.com/suchi/freeway-ss/pull/17))
- 日付: 2026-10-26
- 親計画: [Phase 7 計画](0007-phase7-optional-features.md)
- 関連する決定: [ADR-0007](../adr/0007-localize-ui-strings-in-code.md)(画面の文字列をコードの表に持つ)

本書は、Phase 7.2を別のセッションや別の実装者が引き継げるように、設計と作業手順をまとめたものである。実装は本書とAGENTS.mdに従う。本書と実装が食い違った場合は、実装を変える前に調整役のセッションに伝える(AGENTS.md「複数セッションでの分担」)。

## 1. 目的と完了条件

目的: 設定画面とエラーメッセージを、日本語と英語で表示できるようにする。

2026-10-26にユーザーと決めたこと:

- 言語は設定画面で選べる。選択肢は「自動(Windowsの表示言語)」「English」「日本語」で、既定は自動
- 日本語の訳は3.3節の表のとおり

完了条件:

- 設定画面に言語の選択があり、選ぶとその場で設定画面の表示が切り替わる。OKで保存される
- 自動のとき、Windowsの表示言語が日本語なら日本語、それ以外なら英語で表示される
- エラーメッセージ(設定の保存に失敗したとき・異常終了したとき)が、選んだ言語で表示される
- 文字列の表に、すべての言語の訳がそろっていることのテストがある
- ユーザーが実機で確認する
- ワークスペースのバージョンが`1.2.0`になっている(このPRの最初のコミットで実施済み)

## 2. 前提(Phase 7.1までの状態)

- 設定画面は`freeway.rc`のダイアログ100(224 x 136 DLU、フォントはSegoe UI 9pt)。文字列は英語で、リソースに直接書いている
- 設定は`HKCU\Software\NightFreewaySS`の`REG_DWORD`(`SpeedKmh`・`LeftHandTraffic`・`ShowSpeedometer`・`ShowUfo`)。`Settings::from_raw`が項目ごとに検証する
- エラーメッセージは、`freeway-scr`の`main.rs`(`Night Freeway SS stopped: ...`)と`win/mod.rs`(`The settings could not be saved: ...`)にある。`...`にはWindowsのエラーの説明が入り、その文はWindowsが表示言語で出す
- 速度の表示(`100 km/h`)と速度計の単位`km/h`は、言語によらない

## 3. 設計

### 3.1 設定

- `freeway-core`に`Language`(`Auto`・`English`・`Japanese`)を加え、`Settings`に`language`(既定`Auto`)を加える
- レジストリ値は`Language`(`REG_DWORD`。0: 自動、1: English、2: 日本語)。0〜2以外は既定値(自動)にする(既存の項目と同じ扱い)
- `from_raw`に引数を加える。将来の項目追加に備えた構造の変更(引数を構造体にまとめるなど)は、今回は行わない(YAGNI)

### 3.2 表示する言語の決め方

- 表示に使う言語(`DisplayLanguage`: `English`・`Japanese`)は、設定の`Language`と、Windowsの表示言語から決める。`Auto`のとき、表示言語の主言語が日本語(`LANG_JAPANESE`)なら日本語、それ以外は英語
- Windowsの表示言語は`GetUserDefaultUILanguage`で取る。決める関数は、取った言語IDを引数で受け取るようにして、OSに依存しない部分をテストする

### 3.3 文字列の表

`freeway-core`に`i18n.rs`(仮)を置き、画面に出す文字列をキー(enum)と`DisplayLanguage`から引けるようにする。訳がない状態をコンパイル時またはテストで検出できる形にする(例: `match`で全組み合わせを書く)。

| キー | English | 日本語 |
| --- | --- | --- |
| 設定画面のタイトル | Night Freeway SS Settings | Night Freeway SS の設定 |
| 巡航速度のラベル | Cruising speed: | 巡航速度: |
| 通行方向のラベル | Driving side: | 通行方向: |
| 左側通行 | Left-hand traffic | 左側通行 |
| 右側通行 | Right-hand traffic | 右側通行 |
| 速度計 | Show speedometer | 速度計を表示する |
| UFO | Show a UFO now and then | ときどき UFO を表示する |
| 言語のラベル | Language: | 言語: |
| 言語の選択肢: 自動 | Automatic (Windows display language) | 自動(Windows の表示言語) |
| 言語の選択肢: 英語 | English | English |
| 言語の選択肢: 日本語 | 日本語 | 日本語 |
| OK | OK | OK |
| キャンセル | Cancel | キャンセル |
| 保存の失敗 | The settings could not be saved: {error} | 設定を保存できませんでした: {error} |
| 異常終了 | Night Freeway SS stopped: {error} | Night Freeway SS が停止しました: {error} |

- 言語の選択肢の「English」と「日本語」は、どの言語で表示しているときも、その言語自身の名前で書く(言語を選ぶ画面の慣例)
- 製品名「Night Freeway SS」と単位「km/h」は訳さない
- メッセージボックスのタイトル(`Night Freeway SS`)も訳さない

### 3.4 設定画面

- 速度計とUFOのチェックボックスの下に、ラベル`Language:`と、ドロップダウンリスト(`COMBOBOX`、`CBS_DROPDOWNLIST`。ID 107)を加える。ダイアログの高さを広げ、OK・Cancelを下に移す
- `WM_INITDIALOG`で、保存されている(または既定の)言語から表示言語を決め、タイトルと各コントロールの文字列を表から設定する。ドロップダウンの項目もこのとき入れる
- ドロップダウンで言語を変えたら(`CBN_SELCHANGE`)、その場で表示言語を決め直し、タイトル・各コントロール・ドロップダウンの項目の文字列を設定し直す(選択中の項目は保つ)。保存はOKのときだけ
- レイアウトは1つで、英語と日本語のどちらの文字列も切れずに収まる幅にする(英語の「Automatic (Windows display language)」が最も長い)
- フォントはテンプレートのSegoe UIのまま。日本語の字形は、Windowsのフォントリンクで代わりのフォントから表示される。見た目に問題があれば実機確認の後に検討する

### 3.5 エラーメッセージ

- `show_error`を呼ぶ前に、設定(読めなければ既定値)から表示言語を決め、表の文から作る
- 異常終了のメッセージは、設定を読む前に起きうる。その場合は、読めた設定または既定値(自動)で決める

## 4. テスト

`freeway-core`(Linux・WindowsのCIで実行):

- `Language`の既定値が自動、レジストリの値0〜2の対応、範囲外は既定値
- 表示言語の決め方: 自動で日本語の言語ID(例: 0x0411)なら日本語、英語(0x0409)やその他(例: 0x0407)なら英語。明示した言語はWindowsの言語によらない
- 文字列の表: すべてのキーとすべての表示言語に、空でない文字列がある。`{error}`を含むキーは、どの言語でも`{error}`を1つ含む

`freeway-scr`(WindowsランナーのCIで実行):

- レジストリ: `Language`を書いて読み戻すと同じ値になる。値がない・範囲外なら既定値

設定画面の表示と切り替えは、ユーザーの実機確認で見る。

## 5. 実機での確認(調整役がユーザーに依頼する項目)

- 設定画面に言語の選択があり、選ぶとその場で表示が切り替わる。OKで保存され、次に開いたときもその言語で表示される
- 自動のとき、Windowsの表示言語(日本語)に従って日本語で表示される
- 日本語・英語のどちらでも、文字が切れずに収まる。DPI 150%などでも崩れない
- 日本語の文字の見た目(フォントリンクによる字形)

## 6. 作業手順

実装用セッション:

1. ワークスペースのバージョンを`1.2.0`に上げる(このPRの最初のコミットで実施済み)
2. `freeway-core`に`Language`・`DisplayLanguage`・文字列の表を、テストとともに実装する
3. `freeway-scr`に、レジストリの`Language`と、Windowsの表示言語の取得を加える
4. 設定画面に言語のドロップダウンを加え、文字列をコードから設定する。その場での切り替えを実装する
5. エラーメッセージを表から作る
6. README(設定の表)・利用者向けの説明書(`packaging/README.md`。日本語と英語)・実装計画の進捗表・0007の表を更新する
7. AGENTS.mdの検証コマンドをすべて実行する(Windowsターゲットのclippyも含む)
8. 1コミット1論理変更でコミットし、プッシュする。コミットの種類はAGENTS.mdの許可リストから選ぶ
9. 敵対的セルフレビューを行い、指摘と対応をPRコメントに記録する
10. CIの成功を確認したら、PRの監視を外して調整役のセッションに完了を報告する

調整役:

11. ユーザーの実機確認とマージの承認を得て、マージする。`v1.2.0`のタグはユーザーが手元からプッシュする
