# Phase 7.1 詳細設計: UFO

- ステータス: 実装済み(レビューと実機確認の待ち)
- 日付: 2026-10-26
- 親計画: [Phase 7 計画](0007-phase7-optional-features.md)、[実装計画](0001-screensaver-implementation-plan.md)の5.4節と11章 D7

本書は、Phase 7.1を別のセッションや別の実装者が引き継げるように、設計と作業手順をまとめたものである。実装は本書とAGENTS.mdに従う。本書と実装が食い違った場合は、実装を変える前に調整役のセッションに伝える(AGENTS.md「複数セッションでの分担」)。

## 1. 目的と完了条件

目的: 本家のイースターエッグ(光の点でできたUFOが飛来し、光線を下ろして去っていく)を、スクリーンセイバーの設定項目として加える。本家はコナミコマンドで呼び出すが、スクリーンセイバーはキー入力で終了するため、設定をオンにすると時々現れる形にする(実装計画のD7)。

2026-10-26にユーザーと決めたこと:

- 出現の頻度: 設定がオンのとき、平均10分に1回(間隔はランダム)
- 設定の既定値: オフ(実装計画の5.4節)

完了条件:

- 設定画面に「UFOを時々表示する」のチェックボックスがあり、OKでレジストリに保存される。既定はオフ
- オンのとき、全画面とプレビューで、平均10分に1回UFOが現れ、約12秒で去る。オフのときは現れない
- UFOの動きと見た目が3.3節・3.4節のとおりである
- UFOの出現の間隔・動き・描画、設定値の検証と保存のテストがある
- ユーザーが実機で確認する(確認用の短い間隔のビルドを使う。3.6節)
- ワークスペースのバージョンが`1.1.0`になっている(このPRの最初のコミットで実施済み)

## 2. 前提(Phase 6までの状態)

- `freeway-core`:
  - `Settings { speed_kmh, left_hand_traffic, show_speedometer }`。生の値から作る`Settings::from_raw`は、項目ごとに検証し、不正な値はその項目の既定値に戻す
  - `SceneConfig { speed_kmh, left_hand_traffic, seed }`
  - `Scene`は、`update(dt)`で時刻(`time`)と向き(`heading`)を進める。`draw`では空(`Sky`)、道路の光、他車の順に描く
  - 空は`SkyView`(`horizon_y`・`focal`・`heading`・`time`など)を使って描く。流れ星はシードから決まるスケジュールで出る
- `Canvas`の描画命令は、`glow`・`light_pool`・`dot`・`sky_band`・`streak`。すべて加算合成
- `freeway-scr`:
  - 設定は`HKCU\Software\NightFreewaySS`の`REG_DWORD`(`SpeedKmh`・`LeftHandTraffic`・`ShowSpeedometer`)
  - 設定画面は`freeway.rc`のダイアログ100(224 x 122 DLU)
- モニターごとに独立した場面を描く(ADR-0003)

## 3. 設計

### 3.1 設定

- `Settings`に`show_ufo: bool`(既定`false`)を加える。`from_raw`に4つ目の引数を加え、0と1以外は既定値に戻す(既存のフラグと同じ扱い)
- レジストリ値は`ShowUfo`(`REG_DWORD`。表示は1、非表示は0)
- 設定画面に、速度計のチェックボックスの下へ、チェックボックス`Show a UFO now and then`(ID 106)を加える。UIラベルは英語(AGENTS.mdの言語ルール。多言語化はPhase 7.2で行う)。ダイアログの高さを広げ、OK・Cancelを下に移す
- `SceneConfig`に`ufo_mean_interval: Option<f32>`(秒)を加える。`None`ならUFOは出ない。`Settings::scene_config`は、`show_ufo`がオンなら`Some(600.0)`(`freeway-core`の定数`UFO_MEAN_INTERVAL_SECONDS`)を入れる。速度計と違い、UFOは場面の一部なので`SceneConfig`に入れる

### 3.2 出現のスケジュール

- `freeway-core`に新しいモジュール`ufo.rs`を置く
- 次のUFOまでの待ち時間は、平均`ufo_mean_interval`秒の指数分布から引く(出現がランダムで、平均の間隔が決まる)。待ち時間は、前のUFOが去った時点から数える。最初の待ち時間は場面の開始から数える
- 乱数は場面のシードから作る(既存の`rng`モジュール)。他の要素(空・他車)の乱数列と独立させる
- 同時に現れるUFOは1機まで
- 時刻は`Scene`の`time`(1フレームの上限で切った時間の合計)を使う。シードと時刻の列が同じなら、出現の時刻も同じになる

### 3.3 動き

1回の出現は約12.2秒で、次の3つの段階からなる(本家の動きを参考にした値)。位置と大きさは、`SkyView`の`focal`を基準(960 px)にした比率で決め、画面の大きさに合わせて伸縮する。以下の`k`は`focal / 960`。

| 時刻(秒) | 段階 | 動き |
| --- | --- | --- |
| 0〜3 | 飛来 | 左右どちらか(ランダム)の画面外(端から160k px)から、滞空位置へ滑らかに(smoothstep)移る。高さは地平線の高さ(`horizon_y`)の12%から36%へ下りる。進む向きへ最大0.28 rad傾き、到着とともに水平に戻る。最初の0.6秒で現れる(不透明度0から1) |
| 3〜11 | 滞空 | 滞空位置(横は画面幅の38〜62%のランダムな位置、縦は`horizon_y`の36%)の周りで、ゆっくり揺れる(横に±14k px・周期約9秒、縦に±6k px・周期約3.7秒、傾き±0.06 rad) |
| 11〜12.2 | 退去 | 左右どちらか(ランダム。飛来の向きとは独立)の上方へ加速して去る(時間の2乗で、横に画面幅の0.9倍、上に`horizon_y`の0.8倍まで)。最大0.35 rad傾き、大きさは35%まで縮み、消える(不透明度は1から時間の2乗で0へ) |

- 光線: 4.5〜9.5秒に、機体の下から地平線の少し上まで光線を下ろす(前後0.6秒で現れ・消える)
- カーブでの遅れ: 車が曲がると、UFOは背景のように一度取り残され、その後追いつく。向きの変化量×`focal`だけ横にずらし、そのずれを時定数1.25秒(`exp(-0.8 t)`)で0に戻す

### 3.4 見た目

UFOは光の点(`glow`)の集まりで描く。光線だけは新しい描画命令を使う。色は、シアン(90, 255, 220)・マゼンタ(255, 80, 210)・グリーン(150, 255, 90)・白・赤。下の大きさ`R`は縁の半径で74k px(退去中は縮む)、`dot`は光の点の基準の半径で2.3k px。

| 部分 | 描き方 |
| --- | --- |
| 縁の灯火 | 楕円(横R、縦0.26R)の上に18個。毎秒1.8 radで回る。色はシアン・マゼンタ・グリーンの順に繰り返す。奥側は暗く(0.35倍)、6個おきに明るく大きい灯火が走る(毎秒9個分進む) |
| 機体の輪郭 | 楕円(横0.8R、縦0.17R)の上に26個の淡い白い点。上半分を明るく、下半分を暗くする |
| ドーム | 半円の弧3本(点の数13・9・5)の淡いシアンの点。頂上に赤い標識灯があり、0.5秒ごとに点滅する |
| 機体の下 | マゼンタの灯火3個が逆向きに回り、脈打つように明るさが変わる。機体の下にかすかなシアンの光 |
| 光線 | 機体の下(幅0.6R)から地平線の少し上(幅1.9R)へ広がる台形。上が濃く(不透明度0.20)、下が薄い(0.03)シアン。中を、光の粒28個が地平線から機体へ昇る |

- 描く順: 空(星・街明かり・流れ星)の後、道路の光の前。UFOは遠くにあるので、道路や他車の光が手前に重なる
- 光線のために、`Canvas`に台形の光を描く命令を加える(例: `beam(top_center, top_half_width, bottom_y, bottom_half_width, color, top_alpha, bottom_alpha)`)。Direct2Dでは、パスジオメトリを線形グラデーションのブラシで、加算合成で塗る。命令の名前と引数は実装で決めてよい
- 本家の動きと見た目を参考にするが、コードは移植せず、このリポジトリの構造(`Scene`・`SkyView`・`Canvas`)に合わせて独自に書く(READMEの謝辞の方針)

### 3.5 画面とモニター

- プレビュー(約152 x 112 px)でも、設定がオンなら現れる。大きさは`focal`に比例するので、小さく描かれる
- 複数のモニターでは、モニターごとの場面が独立しているので、UFOもモニターごとに別々の時刻に現れる(ADR-0003)
- 速度計の表示とは関係しない

### 3.6 実機確認の補助

平均10分に1回では、実機で確かめにくい。`freeway-scr`にCargoのフィーチャー`ufo-demo`(既定は無効)を加え、有効にしたビルドでは平均の間隔を20秒にする。設定画面のオン・オフはそのまま効く。

- 実機確認の手順: `cargo build --release -p freeway-scr --features ufo-demo`でビルドし、`target\release\freeway-scr.exe /s`で確かめる
- 配布物(`cargo xtask dist`・リリース)では有効にしない。CIでは`--features ufo-demo`のビルドとテストも行い、壊れていないことを確かめる(`ci.yml`の変更が要る場合は、調整役がユーザーの承認を得て行う)

## 4. テスト

`freeway-core`(Linux・WindowsのCIで実行):

- 設定: `ShowUfo`の既定値がオフ、0と1以外は既定値になる。`scene_config`で、オンなら`Some(600.0)`、オフなら`None`
- スケジュール: 同じシードなら同じ時刻に現れる。オフなら何時間進めても現れない。多数のシードで、出現の間隔の平均が600秒に近い(許容範囲を決めて統計的に確かめる)。同時に2機は出ない
- 動き: 飛来の開始時は画面外、滞空中は画面内、12.2秒を過ぎると消える。カーブでのずれが時間とともに0に近づく
- 描画: UFOが出ている時刻に`draw`すると、UFOの光(`glow`)と光線の命令が出る。出ていない時刻には出ない(記録用の`Canvas`で確かめる)

`freeway-scr`(WindowsランナーのCIで実行):

- レジストリ: `ShowUfo`を書いて読み戻すと同じ値になる。値がない・範囲外なら既定値
- 描画: 既存の非表示ウィンドウのテストで、光線の命令を含む描画が失敗しない

設定画面とUFOの見た目は、ユーザーの実機確認で見る。

## 5. 実機での確認(調整役がユーザーに依頼する項目)

- 設定画面にUFOのチェックボックスがあり、オン・オフが保存される。DPI 150%などでも崩れない
- `ufo-demo`のビルドで、UFOが飛来・滞空・光線・退去の順に動き、見た目が本家に近い
- カーブでの遅れと追いつきが自然に見える
- プレビューでの見え方
- 設定をオフにすると現れない

## 6. 作業手順

実装用セッション:

1. ワークスペースのバージョンを`1.1.0`に上げる(このPRの最初のコミットで実施済み)
2. `freeway-core`の`Settings`と`SceneConfig`に項目を加え、テストを加える
3. `ufo.rs`(スケジュール・動き・描画)と`Canvas`の光線の命令を、テストとともに実装し、`Scene`に組み込む
4. `freeway-scr`のレンダラーに光線の命令を実装する
5. レジストリの`ShowUfo`と、設定画面のチェックボックスを加える
6. `ufo-demo`フィーチャーを加える
7. README(状態・設定の表)・利用者向けの説明書(`packaging/README.md`の設定の表。日本語と英語)・実装計画の進捗表を更新する
8. AGENTS.mdの検証コマンドをすべて実行する(Windowsターゲットのclippyも含む)
9. 1コミット1論理変更でコミットし、プッシュする。コミットの種類はAGENTS.mdの許可リスト(feat・fix・docs・test・refactor・chore・style・ci)から選ぶ
10. 敵対的セルフレビューを行い、指摘と対応をPRコメントに記録する
11. CIの成功を確認したら、PRの監視を外して調整役のセッションに完了を報告する

調整役:

12. `ci.yml`に`ufo-demo`の確認を加える場合は、YAMLをユーザーに提示して承認を得てから行う
13. ユーザーの実機確認とマージの承認を得て、マージする。`v1.1.0`のタグはユーザーが手元からプッシュする
