# ADR-0009: switch-added-features-with-a-scene-mode

- ステータス: 採用
- 日付: 2026-10-28

## 背景

本家(mhatta/nightfreeway)は、大小の光点とその動きだけで、高速道路・遠くの街・空の星を表す。Phase 7からv1.17.0までに、山並み・トンネル・トラック・他車の車体と影・車線変更・時間的な変化・速度計などを、個々の設定項目として加えた。v1.18.0で、本家に近い見え方と、加えた機能を使う見え方を、一度に切り替えたいという要望を受けた(実装計画のD28)。

## 決定

トップレベルの設定「モード」(`Mode`。KitchenSinkは0、Originalは1、既定はKitchenSink)を加える。

- 個々の設定の値は書き換えない。場面の構成(`SceneConfig`)を作るところで、モードがOriginalなら、加えた機能をオフにした値に置き換える(`SceneConfig::original`)。速度計は`Settings::effective_speedometer`で同じように扱う
- 巡航速度・通行方向・表示言語・複数のモニターの扱いは、どちらのモードでも設定どおりにする
- 中央分離帯の街灯の間隔は、構成の値(`SceneConfig::lamp_spacing`)にし、Originalでは本家と同じ45 m、KitchenSinkでは70 mにする
- 本家にある操作(流しているあいだの↑↓・Space・D・F・コナミコマンド)は、Originalでも使える
- 切り替えは、設定画面・コマンドライン(`/original`・`/kitchensink`。その回だけ)・流しているあいだのMキー(その回だけ)で行う
- これから加える機能は、Originalではオフになるようにする(`docs/developers.md`の「モード」)

検討した選択肢と選ばなかった理由:

- 個々の設定の値をまとめて書き換える(プリセット): 戻したときに元の値が失われる。設定画面で灰色にして値を残すほうが、行き来しやすい。
- 機能ごとの既定値をオフにする: 一度に切り替えるという要望を満たさない。既存の利用者の見え方も変わる。

## 結果

- メリット: 本家に近い見え方を、設定を失わずに一度で選べる。KitchenSinkのときの描画は、v1.17.0と変わらない(描画の命令のハッシュのテストで確かめている)。
- デメリット・受け入れたトレードオフ: 新しい機能を加えるたびに、Originalでの扱い(`SceneConfig::original`と設定画面の灰色にする欄)を決める必要がある。流しているあいだにMキーで切り替えると、他車などは作り直される。
- 将来の見直し条件: 3つ以上のモードが必要になった場合。
