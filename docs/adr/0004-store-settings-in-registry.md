# ADR-0004: store-settings-in-registry

- ステータス: 採用
- 日付: 2026-10-26

## 背景

スクリーンセイバーの設定画面(`/c`)で設定した値(巡航速度・通行方向・速度計の表示)を保存し、全画面実行(`/s`)とプレビュー(`/p`)の起動時に読み込む必要がある。設定はユーザーごとに保持する。

## 決定

設定をレジストリの`HKCU\Software\NightFreewaySS`に保存する。値ごとにレジストリ値(数値は`REG_DWORD`)を1つずつ持たせる。読み込み時に値の欠落・範囲外・型違いを検出した場合は、その項目を既定値に戻す。レジストリへのアクセスは`windows`クレートのAPIで行い、追加の依存は入れない。

検討した選択肢と選ばなかった理由:

- `%APPDATA%`配下の設定ファイル(TOML等): 人が編集しやすく移行も容易だが、パーサの依存が増え、ファイルの作成・破損時の扱いを実装する必要がある

## 結果

- メリット: Windowsのスクリーンセイバーで一般的な保存方法で、追加の依存が不要。ユーザーごとに分離される
- デメリット・受け入れたトレードオフ: 設定のバックアップ・移行がファイルより分かりにくい。アンインストール時にレジストリキーが残る(READMEに削除方法を記載する)
- 将来の見直し条件: 設定項目が増えて構造化が必要になった場合(設定値の時間的な変化への対応など)
