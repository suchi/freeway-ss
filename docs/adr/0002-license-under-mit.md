# ADR-0002: license-under-mit

- ステータス: 採用
- 日付: 2026-10-26

## 背景

本リポジトリにはまだライセンスがない。参考にする本家nightfreewayはMITライセンスである。本プロジェクトは本家のコードを移植せず独自に実装するが、挙動・見た目・パラメータ感を参考にするため、本家への謝辞と著作権表示を残しやすいライセンスが望ましい。

## 決定

本リポジトリのライセンスをMITとする。LICENSEファイルとREADMEの謝辞はPhase 0で追加する。謝辞では、本家(mhatta氏)、原作FreeWayの作者FKS氏、Windows移植のYoshihiro Sugahara氏、soyokaze2000.comの再現版に言及する。

検討した選択肢と選ばなかった理由:

- Apache-2.0: 特許条項がある点は利点だが、本家とライセンスが異なり、本プロジェクトの規模では条項の利点が小さい
- その他(GPL系など): 本家より制約が強くなり、配布・再利用のしやすさが下がる

## 結果

- メリット: 本家と同じライセンスで、謝辞と著作権表示の扱いが分かりやすい。利用者・再配布者の制約が少ない
- デメリット・受け入れたトレードオフ: 特許に関する明示的な許諾条項がない
- 将来の見直し条件: 他ライセンスのコード・アセットを取り込む必要が生じた場合
